# Fire Academy 8-Ball: D20 answer-screen simulator

A look-and-feel prototype of the answer display for a hand-held
magic-8-ball-style device for fire-academy classes: a white 3D D20 floating
in dark-blue ink under the glass. One self-contained page, `index.html`, no
build step and no dependencies. Click the screen or the button to shake.

Query params: `?autoask=1`, `?text=<answer>`, `?ff=<seconds>` (fast-forward
a shake).

Live: https://nicksramcik.github.io/8ball-sim/
